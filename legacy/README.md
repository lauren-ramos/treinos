# Meu Treino

App de treino de academia (HTML + JavaScript puro). Abre o `index.html` no navegador.

- Treinos a partir de transcrições de vídeos, com o passo a passo de cada exercício
- Modo Casa e Academia
- Plano semanal, frequência, histórico e registo de séries
- Biblioteca de exercícios com fotos (free-exercise-db, domínio público)
- Estilo do Plano CIAAR
